# Building Green (World Bank)

The World Bank's Building Green dataset: building energy codes and standards in 88 economies, what they require (envelope,
HVAC, lighting, renewables and more), which buildings they cover, and how they are enforced, rebuilt monthly by
[AlreadyOpen/world-building-green](https://github.com/AlreadyOpen/world-building-green) from the World Bank's workbook.

- `building-green.json`: every field, by ISO3 code (`countries`), with the indicator names (`indicators`).
- `building-green.xlsx`: the World Bank's workbook, unchanged.
- `index.json`, `manifest.json`: counts, sha256 and the source.
